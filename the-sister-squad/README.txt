THE SISTER SQUAD — SHOPPING DEMO

HOW TO OPEN THE UPDATED WEBSITE
1. Extract this ZIP file completely.
2. In VS Code, choose File > Open Folder.
3. Select the extracted folder named "the-sister-squad" (the folder containing index.html, style.css, script.js, and images).
4. Open index.html using Live Server, or double-click index.html.
5. Click "Shop Designs" in the header, or scroll down to the product cards.

FEATURES
- Fabric project gallery and original images
- Product cards with sample prices
- Add to Bag / cart drawer
- Quantity + and - controls, remove item
- Subtotal, delivery fee and total
- Checkout form with UPI, card and Cash on Delivery demo options
- Demo order confirmation

IMPORTANT
This is a front-end student project demo. No real payment is processed. Real UPI/card payments require a payment gateway and secure backend integration.
